## Method

1. Text, font name, and bold flag are read per text span with PyMuPDF.
2. Questions are segmented by week header, question numbering (`1.` inline or a bare number line), and option labels (`(a)` or `a.`); wrapped lines and page breaks are joined.
3. **Font check:** exactly one option per question must be entirely set in a bold font; partially bold options are rejected.
4. **Rendered-page check:** each page is rasterised at 4x; the mean stroke width of the bold option's glyphs must be at least 1.15x that of every other option in the question (bold = thicker, darker strokes).
5. **TRD cross-check:** the bold option text must match the answer-key audit table in `TRD.md` (120 entries parsed).
6. A question is `verified` only when all three checks pass and it has four non-blank, distinct options.
